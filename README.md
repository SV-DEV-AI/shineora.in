# ✨ Shineora – E-Commerce Platform

Shineora is a web-based e-commerce platform built to display and sell products through a clean, user-friendly online store. The website is designed for a smooth shopping experience and focuses on essential e-commerce functionality.

This project was created and deployed on **Hostinger** using **WordPress** and **Elementor**, with the goal of understanding real-world website building, hosting, and online business operations.

---

## 🚀 Features

* Online product catalog
* Clean and responsive UI
* User-friendly shopping experience
* Mobile-friendly design
* Easy content and product management

---

## 🛠️ Tech Stack

* **Platform:** WordPress
* **Page Builder:** Elementor
* **Hosting:** Hostinger
* **Language:** PHP, HTML, CSS
* **Database:** MySQL

---

## 🎯 Purpose of the Project

This project was built as a practical learning experience to:

* Gain hands-on experience with hosting and deployment
* Learn website customization using Elementor
* Manage a real online store
